# Jofra Shop

متجر حقائب نسائية عربي بواجهة RTL، مبني باستخدام React/Vite وExpress.js.

## التشغيل

```bash
cd backend
npm install
npm start
```

في طرفية أخرى:

```bash
cd frontend
npm install
npm start
```

يفتح المتجر على `http://localhost:5173`، والـ API على `http://localhost:5000`.

رقم واتساب موجود في رابط المنتج بصيغة `213XXXXXXXXX` ويجب استبداله برقم البائع الدولي.
