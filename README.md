# Jofra Shop

متجر حقائب نسائية عربي بواجهة RTL، مبني باستخدام React/Vite وExpress.js.

## التشغيل

```bash
cd backend
npm install
npm start
```

في طرفية أخرى:

```bash
cd frontend
npm install
npm start
```

يفتح المتجر على `http://localhost:5173`، والـ API على `http://localhost:5000`.

رقم واتساب موجود في رابط المنتج بصيغة `970XXXXXXXXX` ويجب استبداله برقم البائع الدولي.

العملة المستخدمة هي الشيقل الفلسطيني `₪`، ومعلومات الشحن تشير إلى فلسطين.

من لوحة الإدارة يمكن اختيار صورة رئيسية من الجهاز لتظهر في الصفحة الرئيسية، واختيار عدة صور إضافية لتظهر كمعرض في صفحة تفاصيل المنتج.

## الدخول والإدارة

من زر **تسجيل الدخول** يمكن للمستخدم إنشاء حساب أو المتابعة كزائر. للدخول إلى لوحة الإدارة استخدم:

- البريد: `admin@jofra.com`
- كلمة المرور: `admin123`

تستطيع لوحة الإدارة إضافة وحذف المنتجات والماركات. الماركات الحالية تشمل `BOSS` و`GUCCI` و`MICHAEL KORS` و`Jofra Studio` و`CHANEL`.
